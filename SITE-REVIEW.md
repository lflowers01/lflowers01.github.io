## Verification and limits

- `python -m unittest discover -s tests -p test_site.py -v`: build/link/content and real SQLite/HTTP checks.
- `BROWSER_EXECUTABLE` set to official Chrome for Testing 155.0.8059.84, then `python tests/site_browser.py`: full-site browser checks. Playback adapter tests use an explicitly controlled widget fixture; they do not claim audible playback.
- `python tests/preview_interactions.py`: detailed shared artwork, portrait, flower, theme, footer and responsive interaction checks.
- `git diff --check`: no whitespace errors.
